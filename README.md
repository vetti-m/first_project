# Python Projects

A collection of my first larger Python projects, developed during my Bio Data Science studies.

## Projects

### 🧬 Metazoan Gene Conservation and Loss Analysis
Studies gene conservation and gene loss across metazoan lineages using orthologous group data from the eggNOG5 database, linking protein IDs and species TaxIDs to functional annotations.

### 🌳 Prevotella Phylogenetic Tree
A single-script bioinformatics pipeline analyzing ten *Prevotella* genomes (eight human-associated, two cattle-associated) to reconstruct evolutionary relationships across host niches. Combines gene prediction (Prodigal), ortholog detection (BLASTp/BLASTn with custom filtering), multiple sequence alignment (MUSCLE), and phylogenetic tree construction (IQ-TREE), with results visualized via BioPython's Phylo module.
